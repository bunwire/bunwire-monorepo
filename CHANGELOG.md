# Changelog

All notable Bunwire changes are recorded here.

## 0.1.0 — 2026-08-24

Initial release candidate.

- Platform-independent Core application kernel, DI bindings/tokens/scopes, Provider lifecycle, managed methods, invocation plans, and adapter extension APIs.
- Compiler-driven managed-class and managed-method analysis with deterministic registries and exact caller-visible contracts.
- Vite virtual registry/client modules, exact ambient declarations, watch/HMR invalidation, and byte-stable physical artifact generation.
- Full Electrobun adapter with owned and manual host paths, request/message dispatch, generated positional clients, native parameter injectors, and managed middleware.
- Class-based adapter-driven middleware with static groups/controller mappings and a fake second-adapter proof.
- Release architecture, diagnostics, package exports, clean-install, native smoke, performance, and generated-output gates.

This candidate is prepared for publication but has not been published or tagged by the Milestone 13 work.
